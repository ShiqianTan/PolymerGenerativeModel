# SD-VAE：语法约束潜空间设计耐极端环境聚合物

**论文**：Batra et al., *Polymers for Extreme Conditions Designed Using Syntax-Directed Variational Autoencoders*, Chemistry of Materials 32, 10489–10500 (2020)，[DOI](https://doi.org/10.1021/acs.chemmater.0c03332)。综述参考文献 [65]。

## 生成目标与数据

生成对象为带两个连接端点的重复单元 SMILES，不生成分子量分布、真实整条链或三维构象。

无标签预训练数据约 25 万个假想结构，通过从约 1.2 万种已有聚合物得到的数千个片段组合构建。性能标签另有约 5,000 个 Tg 样本、约 900 个带隙 Eg 样本；图 1 的数量是近似值。必须分别管理这三个集合，不能给所有假想结构填写“实测”标签。[原文图 1、Methods]

三类设计目标：Tg > 600 K；Eg > 6.5 eV；Tg > 500 K 且 Eg > 4 eV。Tg 和带隙是环境性能的代理指标；生成器并未直接优化击穿实验结果。[原文正文第 6 页]

## 表示与模型

1. 建立聚合物 SMILES 的上下文无关文法，解析为语法树，取产生式序列并 one-hot 编码。
2. 编码器输出高斯分布的均值 μ 和方差参数；用重参数化得到 z。
3. 解码器按产生式展开语法树。每一步根据当前树节点掩蔽不适用规则；语义属性进一步限制价态、环闭合和链端数目。
4. 论文比较 64 与 128 维潜空间，分别称 VAE-64 与 VAE-128。
5. 编码有标签聚合物，分别训练 z → Tg、z → Eg 的高斯过程回归器。生成器和 GPR 分阶段训练，不是一个端到端条件 VAE。[Methods、图 1]

## 损失函数与实现

记产生式序列为 r，标准 VAE 的负 ELBO 可写为：

$$L_{VAE}=-E_{q_\phi(z|r)}\log p_\theta(r|z)+D_{KL}(q_\phi(z|r)\|N(0,I)).$$

重构项对真实产生式计算交叉熵。规则掩码应先作用在 logits，再归一化；不能先 softmax 后将非法项置零而不重新归一化。对角高斯 KL 为

$$D_{KL}=\frac12\sum_j(\mu_j^2+\exp(\ell_j)-1-\ell_j),\quad \ell=\log\sigma^2.$$

这两个式子是对原方法的统一记号表达。不要自行给标准 ELBO 加入性质 MSE 后仍声称复现原文。GPR 通过核矩阵边际似然拟合，其性质不确定度来自 GPR，不是 VAE 解码概率。

## 生成算法

先从已知或枚举结构中找满足目标的父代，编码到潜空间；在目标区域做潜向量插值，使用 GPR 预筛选；将候选 z 解码为 SMILES；再解析、编码、重新预测并过滤。最后一次重新编码非常重要，因为解码输出的结构不一定准确对应最初的潜向量。[图 1(c)、Design via Generation]

```text
fit VAE(unlabelled grammar_sequences)
fit GPR_Tg(encode(labelled_Tg), Tg)
fit GPR_Eg(encode(labelled_Eg), Eg)
for z in interpolate(target_parent_latents):
    if not surrogate_targets_met(z): continue
    s = grammar_and_semantic_decode(z)
    if not valid_polymer(s): continue
    z_reencoded = encode(s)
    if surrogate_targets_met(z_reencoded): save(s, prediction, uncertainty)
```

## 实际复现顺序

先实现一份固定产生式词表，验证 SMILES → 树 → SMILES 的无损转换；保存所有语义属性的规则版本。用小批数据确认规则掩码确实防止非法树展开。随后训练无标签 VAE，再独立训练两套 GPR，最后做搜索。将训练集、语法与词表、性质单位、核函数参数和候选随机种子一起保存。

重构评估原文对每个聚合物编码 10 次、每次解码 100 次，统计严格与松弛重构；不能用一次 teacher-forcing token accuracy 代替这两个指标。[Results]

## 超参数与缺口

已确认：潜维度 64/128、上述结构规模与三个目标阈值。具体编码器卷积宽度、GRU 规模、训练划分及训练细节见 [论文与补充信息](https://doi.org/10.1021/acs.chemmater.0c03332) 的 Methods 和附录；执行前应按原文填写配置，不能采用其他分子 VAE 的默认值。原始片段构库和完整标签并非本包已获取的可直接训练数据；本包不声称已完成训练或数值复现。

建议最小验证：固定一个 latent，重复解码统计分布；去掉语义约束的消融；对潜插值候选执行重新编码；报告先验有效率和目标达成率的分母。小分子 SA score 不能证明聚合路线可行。
