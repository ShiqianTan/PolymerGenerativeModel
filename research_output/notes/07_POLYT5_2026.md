## 任务与数据层次

预训练使用 100,145,883 个虚拟均聚物，来自可采购小分子和已知聚合反应（缩聚、ROMP、click 等）。按 SMARTS 反应与 RDKit 价态检查构库，并包含 Gasteiger 电荷差 <0.001 的筛选和避免 backbiting 成环的规则。这些是化学 plausibility 约束，不能视为每个结构均已合成。[Methods、SI Table S1]

Tg 条件生成微调使用 5130 个有标签聚合物，[SI Table S4]。预训练规模与微调标签规模要分开，千万不能写成一亿条实测结构—Tg 对。

重复单元先从双 * p-SMILES 转为 PSELFIES，使用 At 作为连接点替代物。解码后恢复 *。不执行这层规则时，普通 SELFIES 的“语法可解码”并不保证两个聚合连接点。

## Tokenizer 与架构

SELFIES 方括号 token 基础集 199 个；加起止、PAD、UNK、空白、100 个 sentinel 和性质/数字/单位等额外 token，最终 vocabulary=458。所有 SELFIES token 作为 SentencePiece 预定义项，保持化学 token 的完整性。[Methods]

| 参数 | Small | Medium | Large |
|---|---:|---:|---:|
| d_model | 128 | 256 | 512 |
| encoder/decoder 层数（各） | 3 | 4 | 8 |
| d_ff | 512 | 1024 | 2048 |
| heads | 4 | 4 | 8 |
| d_kv | 32 | 64 | 64 |
| 最大序列长度 | 200 | 200 | 200 |
| 参数量约 M | 1.44 | 7.46 | 58.98 |

T5 使用相对位置编码；以上来自 SI Table S2，不能使用通用 t5-small/base 的尺寸。

## 预训练任务与损失

最多 8 段互不相邻的 masked spans，每段最多 3 token，总 mask 比例最多 15%，两段之间至少一个未遮蔽 token。输入用 sentinel 替代被遮段；目标由 sentinel 和对应缺失片段串联。**decoder 目标不是整条原始序列。**

$$L_{pre}=-\sum_{t\in masked\ target}\log p_\theta(y_t|y_{<t},corrupt(x)).$$

约 90M 样本训练（90%），余下 10% 用于验证与测试，正文未进一步给出二者的精确比例。batch=450，最多 5 epochs，单 NVIDIA L40S，AdamW。预训练学习率等未完整在正文报告，不能将微调 lr 3e-4 直接记为预训练值。[Methods]

## Tg 条件生成微调

encoder 输入 scalar property string，decoder 输出完整 PSELFIES，90/10 训练/验证；不再 span-mask。max length=200；AdamW，lr=3e-4，weight_decay=0.01，batch=16，最多 15 epochs。按 token CE 训练，PAD target 替换为 −100，忽略它们。[Downstream task 2]

$$L_{gen}=-\sum_{t\in nonPAD}\log p_\theta(PSELFIES_t|PSELFIES_{<t},T_g^{target}).$$

没有将真实 Tg MSE 写进生成 loss；Tg target match 是后续预测与筛选。推断用采样，top_p∈{0.75,0.95}，temperature 0.1–2.0、间隔 0.1，比较微调 epoch 1–15。性质预测任务使用 beam=4；不要把这一设置误移到结构生成。[Methods]

## 独立性质预测器

同一预训练模型另行 fine-tune：PSELFIES → 数值串或分类 token。性质任务最多 30 epochs、batch16、lr3e-4、weight decay0.01，训练占比20%–80%，五个随机划分。介电常数输入频率的 log 信息，溶解性额外输入溶剂 SELFIES。数字输出 CE 训练，MAE/RMSE 用于外部评估；不同于回归头直接优化 MSE。

## 生成过滤与评价

SI Figure S7 顺序为 SMILES validity → training-set deduplication → internal deduplication → polymer validity。polymer validity 要求恰好两个 At，且各价态/连接端度满足作者定义的一价要求，随后恢复双 *。

target property 指标例如 Tg=500±50 K 内的比例；另有 SELFIES reproducibility test，检测编码解码一致性，需采用论文对应定义。温度过高可导致更丰富结构也更低连接点通过率，必须记录每一步剩余个数，不能只报告最终有效候选的内部比例。[SI S7–S10]

## 怎样做方法复现

没有原始亿级库时，可使用公开反应模板库构建较小替代库，并清楚标注“方法复现”。实现相同连接点替换、458-token 词表体系、span-mask 任务和小型 T5；独立保留 Tg 标签测试集，先测试 10 条 SELFIES round-trip，再训练。

```text
stage A: construct/open substitute structures -> PSELFIES -> sentinel corruption -> T5 CE
stage B: paired Tg/PSELFIES -> scalar prompt -> full-sequence CE
stage C: generate with top_p and temperature -> decode -> endpoint/dedup filters
stage D: independent predictors -> Tg and Eg filters -> DFT or experiment
```

若要从头复现论文数值，仍需原构库反应、采购结构版本、5130 条标签及原划分、tokenizer 和权重、预训练 lr/warmup 等。这些信息不能靠本笔记凭空补齐。

## 物理与实验验证

候选 DFT：PSP 初始无限链；非周期方向真空 12 Å；VASP PBE 优化、cutoff400 eV、最大力 <0.01 eV/Å；HSE06 电子结构。实验热性质测量区分 DSC 第二次升温与 TGA 5% 失重 Td，二者不可混用。[Methods]

控制器 LLM、PydanticAI 和 Streamlit 用于任务路由；科学预测/生成由 POLYT5 完成。这一 agent 外壳不会改变 token CE 或 T5 参数，不是必须复现的核心训练组件。

本包未训练模型、下载亿级库或执行合成。**可较完整复现方法结构，尚不能承诺公开资源足以重现作者全部数值。**
